# AudioShelf

Локальный плеер аудиокниг и музыкальных альбомов. Capacitor: `www/` (веб-часть) + `android/` (нативная часть: ExoPlayer/Media3, SAF-сканер, виджет).

## Структура `www/`

| Файл | Назначение |
|---|---|
| `app.js` | точка входа: регистрирует экраны и действия в роутере, загружает состояние, кнопка «Назад» |
| `config.js` | **общие константы** для веба и нативного кода: параметры эквалайзера и список аудиоформатов. Gradle генерирует из него `DspConfig.java` и `AudioFormats.java`. Файл должен оставаться JSON-совместимым |
| `js/router.js` | `render()`, `setScreen()`, реестр экранов и действий. Модули общаются через него, поэтому циклических импортов нет |
| `js/db.js` | обёртка над `lib/idb-keyval.js`. Если библиотека не загрузилась — ошибка, а не молчаливая потеря данных |
| `js/storage.js` | хранение (см. ниже) |
| `js/progress.js`, `js/header.js` | прогресс прослушивания; шапка и «сейчас играет» |
| `js/player.js`, `js/sound.js`, `js/native-bridge.js` | воспроизведение (ExoPlayer в нативной сборке, `<audio>` в браузере), эквалайзер |
| `js/scanner.js`, `js/library.js`, `js/meta.js` | сканирование папок, библиотека, обложки и длительности |
| `js/visualizer.js` | визуализаторы (canvas): «Кольцо», «Эквалайзер», «Волны» + переключение «обложка ↔ визуалы» |
| `js/discover.js` | экран «Для вас» (вместо плейлистов): продолжить, подборки, статистика, закладки, случайный выбор. Ничего не хранит, всё считается из библиотеки |

## Свайпы

- **На картинке плеера** (обложка и визуализатор): свайп меняет картинку по кругу — обложка → «Кольцо» → «Эквалайзер» → «Волны» → обложка (влево — дальше, вправо — назад). Последний визуал запоминается.
- **Везде в остальных местах**: свайп переключает разделы нижней панели (Библиотека → Плеер → Для вас → Настройки) по кругу. Плеер пропускается, пока не выбрана книга.
- Не реагируют на свайп: ползунки, окна и боковые панели. Горизонтальная лента (`data-noswipe`, чипы фильтра) забирает свайп только пока она реально прокручивается; если лента помещается на экране или уже упёрлась в край, свайп переключает экран.

## Иконка и бренд

Иконка прежняя: наушники и раскрытая книга. К ней добавлен знак бренда DataLaw (буква «D» на тёмном кружке с золотым ободком, внизу справа) и фон: тёмно-синий градиент (`#1B3E70` → `#081428`). Адаптивная иконка, старые png, сплэш, иконка и обложка для магазина, `favicon.svg` собраны из одного и того же рисунка.

## Язык

Интерфейс на русском и английском. По умолчанию язык берётся из телефона, выбор: «Настройки → Язык». Тексты веба: `www/js/i18n-en.js` (ключ — русская фраза, в коде `t('...')`); тест `tests/i18n.mjs` падает, если у фразы нет английского варианта. Тексты уведомления и виджета: `res/values/strings.xml` (английский) и `res/values-ru/strings.xml`. Новый язык: добавить словарь и строки `values-xx`.

## Книги и музыка

Для музыки (режим «Альбом») везде говорится «трек / треки», для книг — «глава / главы». На обложках в библиотеке нет надписей: значок книги или винила нарисован прямо на обложке, крупно и с тенью. Свайп по картинке в плеере идёт по кругу: обложка → кольцо → эквалайзер → волны → обложка (в обе стороны).

## Экран плеера

- **Книга:** два прогресса: по текущей главе и по всей книге (оба можно перематывать).
- **Альбом:** только прогресс текущего трека.
- Кнопки перемотки показывают шаг (по умолчанию ±10 с). Шаг выбирается в «Настройки → Воспроизведение» и действует везде: в плеере, уведомлении, на экране блокировки и в виджете.

## Режимы воспроизведения (по каждой книге)

Кнопка «Книга / Альбом» на экране плеера, выбор запоминается для каждой книги.

- **Книга** — главы идут подряд без пауз.
- **Альбом** — последние ~3,5 с трека плавно затухают, затем пауза ~2 с, следующий трек плавно нарастает. Затухание и пауза делает нативный сервис (`PlayerService`, математика в `AlbumFade.java`), поэтому работает при выключенном экране. В браузерной версии есть только пауза.

## Хранилище

| Ключ | Содержимое |
|---|---|
| `books` | библиотека без обложек и без настроек книги. Переписывается только при реальных изменениях библиотеки |
| `cover:<id>` | обложка одной книги. Читается лениво, только для показанных строк, текущей книги и плеера |
| `progress` | позиции воспроизведения (крошечная запись, пишется при паузе, перемотке, смене главы и раз в 20 с) |
| `bookprefs` | эквалайзер, громкость, скорость и режим «Книга/Альбом» для книг, у которых они отличаются от стандартных |
| `folders`, `settings`, `foldersSelected` | каждая запись сохраняется отдельно и только когда меняется. Старые `playlists` больше не показываются, но и не удаляются |

Позиция дополнительно дублируется в `localStorage` и в `SharedPreferences` нативного сервиса; при старте берётся самая свежая. Прослушанная до конца книга остаётся на 100 % (`finished`), при нажатии «Играть» начинается сначала.

## Громкость и усиление

Громкость книги — от 0 до 300 %. Выше 100 % это настоящее усиление; перегрузки нет: в нативном плеере за этим следит лимитер `AudioFx` (потолок из `config.js`), в браузерной версии — лимитер и мягкий ограничитель (`WaveShaper`) после него.

## Звонки и уведомления

Воспроизведение останавливается в тот же момент, а при возврате продолжается на 5 секунд раньше (если это начало главы, то с конца предыдущей), чтобы не потерять слова. Источников два, продолжение только когда закончились оба (`Interruption.java`, `PlayerService`):

- **Аудиофокус.** ExoPlayer приостанавливает плеер, когда звонок или уведомление забирает звук. Для речи это относится и к звукам «приглушить», которые приложения запрашивают с фокусом.
- **Режим звонка телефона** (Android 12+, `CallModeWatcher`, разрешений не нужно). Срабатывает с началом рингтона и при ответе, в том числе у мессенджеров, которые не запрашивают фокус.

Пока звонок держит паузу, сервис остаётся **foreground** (`PlayerService.onUpdateNotification`): иначе система считает процесс обычным фоновым и при долгом разговоре убивает его, а в шторке остаётся «мёртвая» кнопка Play. Место прерывания (`QueueStore.saveInterruption`) пишется на диск, поэтому если процесс всё-таки убит, «Играть» в шторке продолжит с того же места минус 5 секунд.

Если вы сами нажали «Играть» во время звонка, автоматического возобновления и отката не будет. Звуки уведомлений, которые не запрашивают аудиофокус, система приложению не сообщает, остановить плеер на них нельзя.

## Ошибки воспроизведения

Временная ошибка чтения (после долгой паузы «заснула» SD-карта или провайдер файлов, сбросилось аудиоустройство) повторяется один раз на том же месте. Только повторная или жёсткая ошибка (файл удалён, формат не поддерживается) пропускает главу и показывает сообщение. Логика в `ErrorRecovery.java`, работает в сервисе, без интерфейса.

Если система убила процесс, пока плеер был на паузе, кнопка «Играть» в шторке восстанавливает очередь и позицию (`QueueStore` + `onPlaybackResumption`).

## Уведомление плеера

Крестик в уведомлении и смахивание приложения из списка недавних полностью останавливают воспроизведение, запоминают позицию и убирают плеер из шторки (`PlayerService.closePlayback`).

## Версия

Только в `package.json` (`version`). Из неё берутся `versionName` и `versionCode` (2.2.0 → 20200) в `android/app/build.gradle`; в «Настройках» версия читается через `@capacitor/app`.

## Безопасность

- `setWebContentsDebuggingEnabled` включается только в debug-сборке.
- CSP разрешает только `'self'`, `data:`, `blob:` (без `unsafe-eval`, без внешних хостов). `script-src` оставляет `'unsafe-inline'` из-за инлайн-скрипта Capacitor; собственный код инлайн-обработчиков не использует.
- Доступ к папкам только на чтение, `allowBackup="false"`, `FileProvider` не используется.
- Разрешение `INTERNET` оставлено сознательно: Capacitor отдаёт WebView приложение с `https://localhost`. Само приложение сетевых запросов не делает.

## Публикация в Google Play

Всё нужное лежит в `store/`: `RELEASE_CHECKLIST.md` (пошагово), `PLAY_CONSOLE_ANSWERS.md` (анкеты консоли), тексты карточки, политика конфиденциальности, значок и баннер. Подписанный AAB собирает `.github/workflows/release.yml` (секреты описаны в чек-листе) или `./gradlew bundleRelease` локально. Play требует `targetSdk 36`: проект собирается на **Capacitor 8** (Node 22, JDK 21, Gradle 8.14, AGP 8.13).

## Сборка и проверки

```bash
npm ci
npx cap sync android        # создаёт android/app/capacitor.build.gradle и android/capacitor.settings.gradle
cd android && ./gradlew assembleDebug
```

APK: `android/app/build/outputs/apk/debug/app-debug.apk`. Файлы `capacitor.build.gradle` и `capacitor.settings.gradle` генерируются `cap sync` и добавлены в `.gitignore`.

```bash
cd tests && npm ci
npm run lint        # no-undef и прочее по www/
npm test            # smoke-тесты (jsdom + фейковый нативный плеер), визуализатор, объём записей в IndexedDB
cd ../android && ./gradlew testDebugUnitTest      # JUnit: AudioFx, AlbumFade
```

## Версии пакетов

`tests/versions.mjs` (входит в `npm test` и в CI) проверяет: `@capacitor/android`, `cli` и `core` одной версии; `package-lock.json` совпадает с `package.json`; `targetSdk` ≥ 35 (требование Google Play); все модули Media3 на одной версии. Dependabot (`.github/dependabot.yml`) собирает обновления Capacitor в один pull request. Release-сборка по тегу падает, если тег не равен версии из `package.json`.
