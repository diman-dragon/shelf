# Публикация в Google Play: что здесь лежит

| Файл | Для чего |
|---|---|
| `RELEASE_CHECKLIST.md` | пошаговый выпуск: ключ, сборка AAB, тестирование, проверка на устройстве |
| `PLAY_CONSOLE_ANSWERS.md` | ответы для всех анкет консоли: безопасность данных, рейтинг, службы, разрешения |
| `LISTING_RU.md`, `LISTING_EN.md` | название, краткое и полное описание магазина (с проверенной длиной) |
| `PRIVACY_POLICY.md` | политика конфиденциальности (RU + EN), подставьте дату и e-mail, опубликуйте по ссылке |
| `graphics/icon-512.png` | значок 512×512 |
| `graphics/feature-graphic-1024x500.png` | баннер 1024×500 |

**Что нужно сделать вам** (нельзя сделать за вас): создать ключ загрузки и аккаунт Play, подставить дату и e-mail в политику и опубликовать её по ссылке, снять скриншоты, пройти ручную проверку на телефоне.
