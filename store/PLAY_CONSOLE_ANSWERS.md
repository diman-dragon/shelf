# Ответы для Google Play Console

Готовые формулировки для анкет. Проверьте их по факту перед отправкой: формы в консоли иногда меняются.

## Основные сведения
| Поле | Значение |
|---|---|
| Название | AudioShelf: аудиокниги (до 30 символов, см. `LISTING_RU.md`) |
| Идентификатор приложения | `com.shelf.player` (после первой загрузки изменить нельзя) |
| Тип | Приложение, бесплатное, с покупками в приложении |
| Категория | «Книги и справочники» (альтернатива: «Музыка и аудио») |
| Теги | аудиокниги, плеер, музыка, подкасты |
| Контакты | e-mail разработчика (обязательно), сайт (по желанию) |
| URL политики конфиденциальности | ссылка на опубликованный `PRIVACY_POLICY.md` (GitHub Pages / Gist / сайт) |

Что снять: библиотека; плеер в режиме «Книга» (два прогресса); плеер в режиме «Альбом»; настройки (шаг перемотки); уведомление в шторке. Для планшетов скриншоты желательны, но не обязательны.

## Безопасность данных (Data safety)
- Собирает ли приложение данные: **Нет** (оплату и проверку покупки выполняет сам Google Play, приложение платёжные данные не получает).
- Передаёт ли данные третьим лицам: **Нет**.
- Шифрование при передаче: не применимо (приложение своих данных не передаёт).
- Можно ли запросить удаление данных: данные хранятся только на устройстве, удаляются вместе с приложением.

## Рейтинг контента (IARC)
Анкета: насилие, сексуальный контент, ненормативная лексика, азартные игры, наркотики, пользовательский контент, обмен геолокацией, покупки, обмен личными данными: **везде «Нет»**. Ожидаемый результат: «Для всех» / 3+.

## Целевая аудитория
Выберите **18+** или **13+**. Не отмечайте группы до 13 лет, чтобы не попасть под требования Families Policy: приложение не детское.

## Разрешения и службы (форма «Разрешения для служб переднего плана»)
Манифест объявляет:

| Разрешение / служба | Зачем (текст для формы) |
|---|---|
| `FOREGROUND_SERVICE_MEDIA_PLAYBACK` | **Воспроизведение аудиокниг.** Служба `PlayerService` (Media3) играет книгу при выключенном экране и показывает плеер в шторке. Пользователь запускает воспроизведение кнопкой «Играть». |
| `FOREGROUND_SERVICE_DATA_SYNC` | **Сканирование папок пользователя.** Служба `ScanService` читает выбранные папки с аудиофайлами, определяет книги, длительности и обложки, а также **скачивает книгу из каталога в папку пользователя**, показывая прогресс в уведомлении. Запускается пользователем (кнопки «Добавить папку», «Скачать») и останавливается по завершении. |
| `POST_NOTIFICATIONS` | Показ плеера и прогресса сканирования. Запрашивается один раз. |
| `WAKE_LOCK` | Непрерывное воспроизведение при выключенном экране. |
| `INTERNET` | **Каталог бесплатных книг** (только `archive.org`: поиск, прослушивание онлайн, скачивание по действию пользователя), встроенный веб-компонент (Capacitor отдаёт приложение с `https://localhost`) и Google Play для оплаты. Библиотека и прослушивание в сеть не отправляются. |

Если форма просит видео: снимите 30–60 секунд экрана телефона. (1) Выбор папки и запуск сканирования с уведомлением. (2) Запуск воспроизведения, выключение экрана, плеер в шторке. Загрузите на YouTube как «Доступ по ссылке» и вставьте ссылку.

Что не используется (в форме отвечать «Нет»): микрофон, камера, геолокация, контакты, SMS, звонки, список приложений, доступ ко всем файлам (`MANAGE_EXTERNAL_STORAGE`), специальные возможности.

## Таргетинг API
Google Play принимает новые приложения и обновления только с `targetSdk 36` (с 31.08.2026). Проект собирается с Capacitor 8, `compileSdk`/`targetSdk` = 36 (`android/variables.gradle`).


## Покупки в приложении (Play Console → Монетизация → Продукты → Разовые продукты)
Создайте четыре товара, **идентификаторы должны совпадать** с `www/config.js` и `BillingPlugin.java` (их проверяет `tests/audit.mjs`):

| ID | Название | Тип | Цена (ориентир) |
|---|---|---|---|
| `premium_lifetime` | AudioShelf Премиум (навсегда) | не расходуемый | 4,99 € / 4,99 $ |
| `tip_tea` | Чашка чая | расходуемый | 1 € |
| `tip_cat_treat` | Лакомство для котика | расходуемый | 3 € |
| `tip_cat_food` | Корм для котика | расходуемый | 5 € |

Описание Премиума: «Эквалайзер и пресеты, усиление громкости до 300 %, выравнивание громкости, визуализаторы, скачивание книг из каталога. Один платёж, без подписки». Для остальных стран цены можно оставить автоматическими.

## Тестирование оплаты
1. Загрузите сборку (AAB) на **внутреннюю** дорожку: без загрузки в Play товары не видны.
2. Консоль → Настройки → **Лицензионное тестирование**: добавьте свой аккаунт Google, платежи будут тестовыми.
3. Проверьте: покупка Премиума, чаевые (повторная покупка того же), отмена, возврат (Премиум должен выключиться после «Восстановить»), переустановка (покупка возвращается).

## Коды активации для тестировщиков
`node tools/make-codes.mjs 20` печатает 20 кодов вида `XXXX-XXXX-XXXX`. Раздайте их в закрытом тестировании. Код открывает Премиум навсегда: «Настройки → Премиум → У меня есть код». Соль для кодов хранится в `www/config.js` (`premium.codeSalt`); если её сменить, все прежние коды перестанут работать.

## Доступ к файлам
Папки выбираются через системный выбор Android с правом чтения. Право записи в папку нужно одной функции: «Удалить с диска» у трека альбома, по команде и с подтверждением. Для политики Play это обычный доступ к хранилищу через Storage Access Framework, отдельных разрешений в манифесте нет.
