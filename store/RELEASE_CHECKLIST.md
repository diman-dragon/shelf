# Чек-лист выпуска в Google Play

## 0. Один раз: аккаунт и ключ
1. Аккаунт разработчика Play Console (разовый взнос). Для **личных** аккаунтов, созданных после ноября 2023, перед выходом в продакшн обычно требуется закрытое тестирование (около 12 тестировщиков, 14 дней подряд). Актуальное требование смотрите в консоли.
2. Создайте **ключ загрузки** (хранить в надёжном месте, не в git, сделать резервную копию):
   ```
   keytool -genkeypair -v -storetype PKCS12 -keystore upload.jks -alias upload -keyalg RSA -keysize 2048 -validity 10000
   ```
3. Включите **Play App Signing** (по умолчанию для новых приложений): Google хранит ключ подписи, у вас только ключ загрузки.
4. Опубликуйте политику конфиденциальности (`store/PRIVACY_POLICY.md`) по ссылке: GitHub Pages, Gist или свой сайт. Подставьте дату и e-mail.

## 1. Перед каждым релизом
1. Поднимите `version` в `package.json` (например, `2.4.0`). Из неё берутся `versionName` и `versionCode` (2.4.0 → 20300), код всегда должен расти.
2. Проверки: `cd tests && npm ci && npm run lint && npm test`, затем `cd ../android && ./gradlew testDebugUnitTest`.
3. Ручная проверка на **реальном телефоне** (минимум Android 15 или 16, лучше ещё один старый), список ниже.

## 2. Сборка подписанного пакета (AAB)
**Локально** (в `android/` создайте `keystore.properties` по образцу `keystore.properties.example`):
```
npm ci
npx cap sync android
cd android
./gradlew bundleRelease
```
Файл: `android/app/build/outputs/bundle/release/app-release.aab`.

**Через GitHub Actions** (`release.yml`): добавьте секреты репозитория
`ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`, затем отправьте тег `v2.4.0` или запустите вручную. Base64 из PowerShell:
```
[Convert]::ToBase64String([IO.File]::ReadAllBytes("upload.jks")) | Set-Clipboard
```
Готовый AAB появится в артефактах запуска.

## 3. Публикация
1. Консоль → «Тестирование» → «Внутреннее тестирование» → загрузите AAB, назначьте себя тестировщиком, установите из Play и проверьте ещё раз.
2. Заполните разделы «Контент приложения» по `PLAY_CONSOLE_ANSWERS.md` (политика, безопасность данных, рейтинг, аудитория, реклама, службы переднего плана).
3. Заполните «Карточку магазина» из `LISTING_RU.md` / `LISTING_EN.md`, загрузите графику из `store/graphics/` и скриншоты.
4. Закрытое тестирование (если требуется), затем «Рабочая версия» и отправка на проверку (обычно от нескольких часов до нескольких дней).

## 4. Проверка на устройстве перед отправкой
Сборка в этой среде не запускалась, поэтому пройдите всё вручную:
- [ ] первый запуск, запрос уведомлений, выбор папки, сканирование (уведомление прогресса, потом исчезает);
- [ ] воспроизведение, перемотка кнопками (шаг из настроек), смена главы, два прогресса в режиме «Книга», один в «Альбоме»;
- [ ] **безрамочный режим Android 15/16**: шапка не залезает под статус-бар, нижнее меню не под панелью навигации, в светлой и тёмной теме читаются значки статус-бара;
- [ ] плеер в шторке: пауза, пуск, перемотка; пауза, подождать несколько минут, пуск; после этого плеер не «глючит», глава не перескакивает;
- [ ] смахнуть приложение из списка недавних: плеер исчезает из шторки, при следующем запуске позиция на месте;
- [ ] входящий звонок и звук уведомления: остановка сразу, продолжение на 5 секунд раньше (не раньше начала главы);
- [ ] режим «Альбом»: затухание в конце трека, пауза, плавный старт следующего;
- [ ] таймер сна, эквалайзер, виджет, поворот экрана, кнопка «Назад»;
- [ ] перезагрузка телефона: библиотека и позиция на месте;
- [ ] отсутствие падений: `adb logcat *:E` во время всех пунктов.

## 5. Если Play вернёт замечания
- **targetSdk**: в `android/variables.gradle` стоит 36. Если требуется выше, поднимите Capacitor, AGP и `compileSdk` вместе.
- **Службы переднего плана**: формулировки в `PLAY_CONSOLE_ANSWERS.md`. Если `dataSync` для сканирования не принят, замените сканирование на `WorkManager` или тип службы `specialUse` с пояснением.
- **R8/сжатие** сейчас выключено (`minifyEnabled false`). Включать только после проверки на устройстве и добавления keep-правил для `com.shelf.player.*` и Capacitor.
- **Страницы памяти 16 КБ** (требование для новых устройств): собственных нативных библиотек в проекте нет, Media3 и Capacitor используют только Java/Kotlin.
